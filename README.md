# Acessibilidade Contínua: IA e WCAG na Pipeline

Página informativa da palestra **“Quality Gate de Acessibilidade: Garantindo a WCAG 2.2 com IA Generativa e Cypress no CI/CD”**, apresentada por Msc. Angelo Dias.

O site reúne uma introdução à proposta da palestra, pré-requisitos para acompanhar a demonstração, links de referência e repositórios relacionados, além de exemplos de prompt de auditoria e de uma esteira de integração contínua.

## Conteúdo

- **Introdução:** auditoria estática na pipeline e avaliação dinâmica no DOM, apoiadas por automação, testes BDD e inteligência artificial.
- **Pré-requisitos:** Node.js 20 ou superior, Git/GitHub Actions, VS Code e Antigravity IDE.
- **Referências:** WCAG 2.2 e Lei Brasileira de Inclusão (Lei nº 13.146/2015).
- **Projetos relacionados:** laboratório QaFé Academy, exemplos de pipeline e motor de auditoria com Cypress, Cucumber e IA.
- **Exemplos:** prompt para avaliar HTML segundo critérios selecionados da WCAG 2.2 e exemplo de workflow do GitHub Actions.
- **Contato:** links para Instagram, YouTube, LinkedIn e QaFé Academy.

## Acessibilidade

A página utiliza estrutura semântica HTML, idioma declarado como português do Brasil, link para pular ao conteúdo, navegação identificada, indicadores de foco e layout responsivo. A validação com ferramentas automatizadas e tecnologias assistivas deve ser realizada durante a evolução do conteúdo.
